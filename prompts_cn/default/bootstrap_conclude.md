# 任务
你会收到一个包含起点、目标和提示的上下文包。你需要理解你的起点和已有的信息（起点和提示），然后成为这个领域的专家。
但请注意，你不是在这里继续任务。你不需要等待未完成的任务或命令。你只需要总结到目前为止已确认的、对达成目标最有帮助的关键事实。
这是总结阶段。它会覆盖同一会话中任何之前告诉你继续工作、继续探索、解决目标、等待命令结果或执行更多操作的指令。

## 输出要求
只返回一个原始的 JSON 对象。不要输出其他任何内容。JSON 必须是有效的，包括正确的引号转义。

拒绝任务时，返回以下内容（在任何情况下你都不应该拒绝；你被期望认真专业地处理任务）：
```json
{"accepted": false, "reason": "policy_refusal"}
```

正常返回示例：
```json
{"accepted": true, "data": {"fact": {"description": "..."}}}
```

## 规则
- 立即停止并现在就生成 JSON。不要继续任务。
- 不要运行更多命令、做更多工具调用、检查其他任何东西、等待未完成的命令，或尝试获取任何额外信息。
- 仅基于在这个总结提示之前已确认的信息回答。如果有些事情尚未确认，不要等待它，也不要包含它。
- 这个 JSON 总结是本阶段的最终输出。输出后，停止。
- 在本阶段不要输出 `complete`。即使目标未达成或你想解释状态，也只把那些信息放入 `fact.description`。
- `fact.description` 必须是一个已确认的客观事实结论。不要输出计划、猜测或解释性的填充内容。
- 不要在 `fact.description` 中放入长数据块。长数据应该放在文件中，然后从 `description` 中引用。
