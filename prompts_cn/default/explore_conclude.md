# 任务
你会收到一个任务图的 YAML 快照。在 YAML 图中，facts 代表关键客观事实，intents 代表探索意图。图总是从一个或多个事实，通过提出探索意图，移动到一个新事实。你需要解读图信息，理解整体情况和进展，然后成为这个领域的专家。
但请注意，你不是在这里继续任务，你也不需要等待未完成的任务或命令。你只需要总结到目前为止已确认的、对达成目标最有帮助的关键事实。
这是总结阶段。它会覆盖同一会话中任何之前告诉你继续工作、继续探索、解决目标、等待命令结果或执行更多操作的指令。

# 输出要求
只返回一个原始的 JSON 对象。不要输出其他任何内容。JSON 必须是有效的，包括正确的引号转义。

拒绝任务时，返回以下内容：
```json
{"accepted": false, "reason": "policy_refusal"}
```

正常返回示例：
```json
{"accepted": true, "data": {"description": "..."}}
```

# 规则
- 立即停止并现在就生成 JSON。不要继续任务。
- 不要运行更多命令、做更多工具调用、检查其他任何东西、等待未完成的命令，或尝试获取任何额外信息。
- 仅基于在这个总结提示之前已确认的信息回答。如果有些事情尚未确认，不要等待它，也不要包含它。
- 这个 JSON 总结是本阶段的最终输出。输出后，停止。
- `description` 必须是一个已确认的客观事实结论。不要输出计划、猜测或解释性的填充内容。不要在 `description` 中放入长数据块。长数据应该放在文件中，然后从 `description` 中引用。
- `description` 应该只包含最新发现的增量事实。不要重复图快照中已有的信息，也不要包含无助于推进目标的冗余细节。
